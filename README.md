# Yonder

Yonder is a podcast, audiobook and radio app for Android, made by BetterBuiltApps.

- Website: https://mattsapps.github.io/yonder/
- Privacy policy: https://mattsapps.github.io/yonder/privacy-policy.html
- Feedback: BetterBuiltApps@gmail.com, or "send feedback" in Yonder (Tune → About Yonder)

## Built on AntennaPod

Yonder is built on [AntennaPod](https://github.com/AntennaPod/AntennaPod), the open-source podcast manager for Android. Thank you to everyone who has worked on it.

## Building

Build it like any other Android project: `./gradlew :app:assembleDebug`.
